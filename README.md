# Compliance Guardian · 合规卫士

> 面向垂直行业的内容合规检测工具，支持多平台规则对比、可插拔行业词库包、本地运行隐私安全。
>
> 源于移民行业内容运营的真实痛点，从 v1.0 到 v2.3 持续迭代的生产级工具。

---

## 为什么做这个

在移民行业做内容运营时，我发现通用合规检测工具（句易网、零克查词等）只能检测广告法极限词，完全覆盖不到行业特有的合规红线：

- "保证下签""包过""成功率100%" — 虚假承诺类
- "内部关系""移民局渠道" — 违法操作类
- "雇主资源现成""快速匹配" — 雇主担保红线
- "X个月必拿PR" — 时间承诺类

这些词在通用词库里根本不存在，但在移民行业是实打实的违规风险。加上小红书/抖音/视频号三个平台的规则差异、企业号与个人号的不同标准，每次发内容都要人工反复核对，效率极低。

所以我做了这个工具——不是又一个违禁词检测器，而是**面向垂直行业的合规助手**。

---

## 核心特性

### 1. 行业词库包架构（可插拔）

内置 **移民行业合规包**，含 140+ 条行业专属规则，覆盖 13 个风险分类：

| 分类 | 示例 |
|------|------|
| 虚假承诺 | 保证获批、保证下签、包过、包拿PR |
| 虚假宣传 | 100%成功、零拒签、史上最快 |
| 雇主担保红线 | 现成雇主、内部名额、担保资源 |
| 违法操作 | 内部关系、暗箱操作、买身份 |
| 成功率宣传 | 成功率99%、百分百通过 |
| 时间承诺 | 3个月出签、最快一周获批 |
| 费用承诺 | 全网最低、不成功全额退款 |
| 关系暗示 | 移民局有人、内部渠道 |

行业包采用 **可插拔架构**，新增行业只需在 `rules/industry_packs/` 下添加一个目录（`pack.json` + `rules.json`），自动加载无需改代码。

### 2. 三平台同时对比检测

一键检测同一文案在 **小红书 / 抖音 / 视频号** 三个平台的合规差异，直观对比各平台风险点不同。

### 3. 多层检测引擎

| 层级 | 技术 | 覆盖范围 |
|------|------|---------|
| 关键词匹配 | Aho-Corasick 自动机 | 938 条精确关键词，O(n) 线性扫描 |
| 正则模式 | 预编译正则表达式 | "最X""极X""第X""首X"等词根组合，12 类模式 |
| 语义增强 | Ollama 本地 LLM | 隐性违规、虚假宣传、语境风险识别（可选） |

### 4. 本地运行，数据不出本机

- 纯本地运行，文案内容不上传任何服务器
- 支持本地 Ollama 大模型做语义增强分析
- 适合对内容保密性要求高的行业

### 5. 词库管理与版本备份

- 可视化增删改自定义规则
- 词库版本备份与一键恢复
- 跨词库去重与冲突检测

## 技术实现

### 架构概览

```
┌─────────────────────────────────────────────────┐
│                   GUI Layer                      │
│  checker.py · dashboard.py · rules_manager.py   │
│         检测页 · 数据看板 · 词库管理             │
└───────────────────┬─────────────────────────────┘
                    │
┌───────────────────▼─────────────────────────────┐
│                  Core Engine                     │
│                                                 │
│  ┌─────────────┐  ┌─────────────────────────┐   │
│  │  AC自动机   │  │   预编译正则模式        │   │
│  │ (关键词匹配)│  │   (词根组合匹配)        │   │
│  └─────────────┘  └─────────────────────────┘   │
│                                                 │
│  ┌─────────────────────────────────────────┐    │
│  │         行业词库包加载器                 │    │
│  │  immigration / study_abroad / ...       │    │
│  │  （插件式架构，自动发现与加载）          │    │
│  └─────────────────────────────────────────┘    │
│                                                 │
│  LLM 语义增强（Ollama 本地模型，可选）           │
└─────────────────────────────────────────────────┘
```

### 关键技术决策

| 决策 | 原因 |
|------|------|
| Aho-Corasick 自动机 | 一次扫描匹配所有关键词，O(n) 复杂度，比逐词扫描快 10-100 倍 |
| 预编译正则 + 词根模式 | "最X""极X"等组合无法穷举，用正则模式覆盖无限变体 |
| 行业包插件架构 | 垂直行业工具的核心是可扩展性，新增行业不修改核心代码 |
| 单例模式 | 多 UI 页面共享检测器实例，避免重复加载词库浪费内存 |
| 原子写入配置 | 防止程序崩溃时配置文件损坏，用 tempfile + rename 保证原子性 |
| 本地 Ollama 而非云端 API | 内容合规场景下，文案不出本机是硬需求 |

## 快速开始

### 安装

```bash
# 克隆仓库
git clone <repo-url>
cd compliance-guardian

# 安装依赖
pip install -r requirements.txt

# 运行
python app.py
# 或 Windows 双击 run.bat
```

### 代码示例（API 调用）

```python
from core.detector import ComplianceDetector

detector = ComplianceDetector.get_instance()

# 单平台检测
result = detector.detect(
    text="我们保证下签，成功率100%，最快3个月获批",
    platform="xiaohongshu",  # xiaohongshu / douyin / weixin
    account_type="personal"   # blue_v / personal
)

print(f"违规 {result['summary']['violations']} 条")
print(f"警告 {result['summary']['warnings']} 条")
print(f"合规分: {result['summary']['score']}")

# 三平台对比
results = detector.detect_all_platforms(text, "personal")
for plat, res in results.items():
    print(f"{plat}: {res['summary']['score']}分")

# 查看可用行业包
packs = detector.list_industry_packs()
for p in packs:
    print(f"{p['name']}: {p['rule_count']} 条规则")
```

### 运行测试

```bash
pip install -r requirements-dev.txt
python -m pytest tests/ -v
```
